# Example weekly reports (demonstration data)

> **Demonstration data.** Every user, session, set and note below was generated by a script (`gym/test/example-reports.js`) to show what the planning engine and weekly review produce. None of it is a real person's training. The reports are produced by the same code the app runs, and the "saved plan change" lines are read back from the plan after it was changed.

No AI service was called. The written feedback section in the app comes from the configured AI service when there is one; otherwise the statistics summary shown here is used and is labelled as not written by AI.
